# Happy Birthday

A polished birthday greeting page for **Mukisa Divine Adriel**.

## What’s included

- Animated greeting card with floating celebratory emojis
- Responsive layout optimized for mobile and desktop
- Elegant dark gradient theme with subtle sparkle effects
- Simple one-page HTML file for easy deployment

## Usage

Open `index.html` in your browser to view the birthday greeting.

## Deploy to GitHub Pages

1. Push the repository to GitHub.
2. Enable GitHub Pages in repository settings using the `main` branch.
3. Your page will be available at `https://mitoyo-1.github.io/Happy-birthday-/`.
